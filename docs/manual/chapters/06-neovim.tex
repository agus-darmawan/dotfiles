\chapter{Neovim}\label{ch:neovim}

Neovim is configured in \file{nvim/.config/nvim/} with about twenty plugins managed by lazy.nvim:
blink.cmp (completion), snacks.nvim (pickers, explorer, terminal, lazygit), which-key, gitsigns,
conform (formatting), nvim-lspconfig with Mason, nvim-treesitter, flash, mini.surround and
mini.pairs.

\screenshot{nvim}{clangd completion with the signature of the selected member, in a container over SSH.}

\section{First steps}

\begin{itemize}
  \item New to Vim motions? Run \cmd{:Tutor} first (about 30 minutes).
  \item Press \key{Space} and wait: which-key lists every group and key. \key{Space sk} searches all
        keymaps.
  \item \cmd{:Lazy} shows the plugins, \cmd{:Mason} the language servers and tools,
        \cmd{:checkhealth} what is missing.
\end{itemize}

\section{Code}

These keys work in a buffer with a language server attached.

\begin{keys}{4cm}
\head{Keys}{Action}
\key{gd}, \key{gD}, \key{gr}, \key{gI}, \key{gy} & Definition, declaration, references, implementation, type definition\\
\key{K} / \key{gK} & Hover documentation / signature help (\key{C-k} in insert mode)\\
\key{Space ca} & Code action (imports, quick fixes)\\
\key{Space cr} & Rename the symbol in the whole project\\
\key{Space cR} & Rename the file and update imports\\
\key{Space cf} & Format (format on save is on; \key{Space uf} toggles it)\\
\key{Space cd} & Diagnostics of the current line\\
\key{Space ch} & Switch between header and source (C/C++)\\
\key{Space ss} / \key{Space sS} & Symbols in the buffer / workspace\\
\key{]d} \key{[d}, \key{]e} \key{[e} & Next / previous diagnostic, error\\
\key{]]} \key{[[} & Next / previous reference of the word under the cursor\\
\key{Space xx} / \key{Space xq} & Project diagnostics / toggle the quickfix list\\
\key{Space cl} & LSP health check\\
\key{Space cm} & Mason\\
\end{keys}

Completion: \key{Tab} / \key{S-Tab} select, \key{Enter} accepts, \key{C-Space} opens the menu.

\section{Languages}

Every language is registered in one file, \file{lua/config/languages.lua}: the Treesitter parser,
the language server and the formatter.

\begin{keys}{3.6cm}
\head{Language}{Server, formatter}
C / C++ & clangd; clang-format, only when the project has a \file{.clang-format}\\
Python & basedpyright, ruff (lint and format)\\
CMake & neocmake\\
ROS XML, URDF, xacro, launch & lemminx\\
\texttt{.msg} / \texttt{.srv} / \texttt{.action} & Syntax highlighting\\
TypeScript, React, Next.js & vtsls, ESLint, Tailwind CSS; biome when \file{biome.json} exists, otherwise prettier\\
HTML, CSS, JSON, YAML, TOML & html, cssls, jsonls (with SchemaStore), yamlls, taplo\\
Bash / zsh & bashls, shfmt\\
Docker & dockerls\\
Dart & dart language server when the Dart SDK is installed\\
Lua & lua\_ls, stylua\\
\end{keys}

On machines without internet (robots), \texttt{export NVIM\_OFFLINE=1} in \file{~/.zshrc.local}
skips every automatic download of parsers, servers and plugin updates.
